## 🧑‍💻 Sobre mí

Soy desarrollador de sistemas en **Credifac**, donde trabajo en el ciclo completo del producto: backend, frontend web y aplicación móvil, además de bases de datos e infraestructura. Me gusta crear soluciones escalables, mantenibles y que resuelvan problemas reales del negocio.

- 🏢 Desarrollador de sistemas en **Credifac**
- 🗄️ Administración y diseño de bases de datos (reportes, consultas y optimización)
- 🤖 Explorando IA aplicada al desarrollo
- 🌱 Aprendiendo y compartiendo conocimiento de forma constante
